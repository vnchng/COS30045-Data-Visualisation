# The Price of Socioeconomic Health Inequality

A data visualisation project developed for COS30045 Data Visualisation at Swinburne University of Technology.

## Authors

- Vanessa Chung
- Riya Malik

## Project Overview

This project explores socioeconomic health inequality across OECD countries using interactive data visualisations.

The project investigates healthcare expenditure, healthcare coverage, and differences in reported health outcomes across countries and socioeconomic groups.

## Data

The project uses datasets from OECD Health Statistics, including:

- [Healthcare expenditure and financing](https://data-explorer.oecd.org/vis?fs[0]=Topic%2C1%7CHealth%23HEA%23%7CHealth%20expenditure%20and%20financing%23HEA_EXP%23&pg=0&fc=Topic&bp=true&snb=4&df[ds]=dsDisseminateFinalDMZ&df[id]=DSD_SHA%40DF_SHA&df[ag]=OECD.ELS.HD&dq=.A.EXP_HEALTH.PT_B1GQ._T.._T.._T...&pd=2015%2C&to[TIME_PERIOD]=false)

- [Health insurance coverage](https://data-explorer.oecd.org/vis?fs[0]=Topic,1%7CHealth%23HEA%23%7CHealthcare%20coverage%23HEA_COV%23&pg=0&fc=Topic&bp=true&snb=1&vw=ov&df[ds]=dsDisseminateFinalDMZ&df[id]=DSD_HEALTH_PROT%40DF_HEALTH_PROT&df[ag]=OECD.ELS.HD&dq=.A...&pd=2010,&to[TIME_PERIOD]=false)

- [Perceived health status by socioeconomic status](https://data-explorer.oecd.org/vis?lc=en&df[ds]=dsDisseminateFinalDMZ&df[id]=DSD_HEALTH_STAT%40DF_PHS_SES&df[ag]=OECD.ELS.HD&df[vs]=1.0)

Raw datasets are cleaned and processed before being used in the visualisations.
